# Свой сервер

## Быстрый старт

1. Установите бесплатный Wine в «Настройки → Запуск». Можно продолжать играть через CrossOver: сервер использует независимый Wine.
2. Подготовьте `acServer.exe` из собственной установки Assetto Corsa Dedicated Server (Steam → Инструменты) или папки `server` установленной игры. Paddock не скачивает и не распространяет серверные бинарники.
3. Откройте «Онлайн → Свой сервер». Выберите машину, трассу, layout, число мест и при необходимости пароль.
4. Если файл не найден в игре, откройте «Дополнительно → Выбрать acServer.exe». Нажмите «Создать и запустить».
5. Откройте журнал: статус запуска процесса ещё не подтверждает сетевую готовность. Первый старт создаёт отдельный Wine prefix и может занять больше времени.
6. На том же Mac подключитесь через «Онлайн → Каталог серверов → По адресу»: `127.0.0.1:8081` (либо заданный HTTP-порт). Друзьям в LAN передайте IP Mac и этот порт. Машина и трасса должны совпадать по версии.

Первый мастер поддерживает одну модель машины с упакованным `data.acd`, реальные скины и обычную тренировку от 1 до 240 минут. Вместимость не превышает число пит-боксов layout и 64 места. При отсутствии `surfaces.ini` подготовка откатывается. Поддержка unpacked physics, CSP, AI-трафика и нескольких событий остаётся отдельной работой.

## Интернет и стоимость

Домашний сервер не требует обязательной аренды или платного менеджера; нужны собственная игра, включённый Mac и интернет. Опциональная публикация в лобби не настраивает сеть. По умолчанию используется частный LAN-сервер.

На роутере и в firewall разрешите игровой порт 9600 TCP/UDP и HTTP 8081 TCP либо свои значения из «Дополнительно». Для друзей за пределами LAN используйте внешний адрес. При CGNAT понадобятся внешний IP у провайдера либо VPN, поддерживающий входящие соединения. Paddock не покупает услуги и не меняет роутер автоматически. Ссылка/адрес подключения не содержит пароль: передавайте его отдельно.

## Хранение и остановка

Каждое создание формирует новую папку `~/Library/Application Support/MozaPaddock/Servers/<UUID>`: копия пользовательского executable и соседних DLL, физические данные машины и surfaces трассы, `cfg/server_cfg.ini`, `cfg/entry_list.ini`, `server.log`. Исходный сервер и игровые INI не перезаписываются. Секреты находятся только в приватной серверной папке (0700, INI 0600); admin-пароль генерируется случайно и доступен в файле конфигурации. Серверные папки не входят в git и сохраняются после остановки; их можно открыть кнопкой «Файлы сервера».

`Scripts/paddock-server.py` использует закреплённую независимую Wine-среду и отдельный prefix `Prefixes/server`. Игровой prefix `Prefixes/assetto` и бутылки CrossOver не используются для сервера. Кнопка «Остановить» завершает только дочерний процесс сервера; если он не ответил на SIGTERM за пять секунд, завершается этот же принадлежащий приложению процесс. При обычном выходе из приложения также отправляется SIGTERM. При переключении вкладок процесс продолжает работать. Возобновление управления сервером после аварийного завершения приложения пока не поддерживается; для гарантированной остановки используйте кнопку перед выходом.

Ошибки Wine/занятых портов/бинарника отображаются в журнале. Счётчик игроков и автоматическая проверка доступности извне пока не реализованы. Аппаратные тесты, реальная LAN-сессия и подключение через интернет — отдельные ручные проверки; офлайн-тесты не подтверждают их.
