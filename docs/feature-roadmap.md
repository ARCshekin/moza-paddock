# Развитие Paddock: Content Manager и MOZA Pit House

Исследовано 9 ноября 2026 года. Приоритет P1 — ближайший этап, P2 — следующий, P3 — долгосрочный. Сложность S/M/L/XL — относительная оценка объёма и неопределённости, не обещание срока.

## Что уже есть

Paddock уже запускает локальные и онлайн-заезды, сканирует машины/трассы/скины, устанавливает архивы модов с откатом, хранит пресеты и историю, разделяет рекорды по конфигурации, настраивает руль, педальные кривые и кнопки. Wine и CrossOver поддерживаются отдельными путями. Эти возможности повторно не записаны как новые фичи.

## Основания сравнения

[Content Manager — официальный список](https://acstuff.club/app/): запуск, онлайн с избранным, контент, результаты, обмен пресетами, повторы, погода и CSP; управление серверными пресетами и чемпионаты указаны автором среди WIP-возможностей. CSP является отдельным проектом. Расширения Paddock ниже не обещают полной совместимости CM/CSP.

[MOZA Pit House — официальный обзор](https://mozaracing.com/pages/pit-house): мониторинг устройств, готовые настройки, расширенный FFB, настройка педалей, органов управления и RPM LED, обновления устройств. Для macOS аппаратные расширения требуют исследования протокола, поддержки в MozaKit и отдельных испытаний.

Формат базового серверного INI сверен с [исходным конфигом AssettoServer](https://github.com/compujuckel/AssettoServer/blob/master/AssettoServer/Assets/server_cfg.ini) и [конфигурацией Assetto Corsa Server Manager](https://github.com/JustaPenguin/assetto-server-manager/blob/master/config_ini_default.go). Генератор Paddock предназначен для обычного Kunos acServer.exe, без AssettoServer-специфичных функций.

## Навигация

- Заезд — текущий быстрый старт.
- Онлайн → Каталог серверов, Свой сервер.
- Библиотека → Пресеты, Моды, Рекорды.
- Настройки → Руль и кнопки, Запуск.

Состояние редактируемых конфигураций и серверного процесса живёт независимо от открытой вкладки. Все существующие экраны сохранены. Аварийная остановка отдачи остаётся внизу бокового меню.

## Границы первого мастера сервера

Домашний хостинг без обязательной подписки: сборка автоматически импортирует закреплённый acServer.exe из Steam-файлов пользователя и устанавливает Wine штатным установщиком Paddock. Генератор поддерживает тренировку, квалификацию, гонку и уикенд с несколькими моделями, скинами по местам и общим ограничением по пит-боксам. Требуются data.acd машины и surfaces.ini выбранного layout трассы. Подробности запуска и ограничений — [server-hosting](server-hosting.md).

Доступ из интернета требует входящих соединений; публикация в лобби не решает NAT/CGNAT. Автоматическая настройка роутера, аренда сервера, AI-трафик, CSP и управление прошивками не входят в эти три реализации.

## Несколько автомобилей и режимы сервера

[#32](https://github.com/ARCshekin/moza-paddock/issues/32), P1 / M: добавление нескольких моделей из установленной библиотеки при создании одного сервера, число мест для каждой модели и выбор скинов по слотам. Например, 2 Audi + 2 Lotus. Общее число мест ограничивается пит-боксами трассы; проверяются данные всех машин, конфигурация и checksum-файлы готовятся с общим откатом. Доступные модели и места должны отображаться в подключении и приглашении. Текущий простой сценарий с одной машиной сохраняется. Статус — реализовано. Добавлены выбор режима и отдельная вкладка LAN внутри каталога серверов.
