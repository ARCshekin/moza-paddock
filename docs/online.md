# Онлайн

Вкладка «Онлайн» загружает публичный каталог [acservers.online](https://acservers.online/servers), поддерживает поиск по названию, машине и трассе, страницы и фильтр свободных мест. Отдельные поля «Фильтр по трассе» и «Фильтр по автомобилю» сужают текущую страницу по названиям из каталога. Фильтр «Есть все моды» дополнительно запрашивает `/INFO` серверов этой страницы (до четырёх параллельных запросов) и сверяет точные ID всех машин и конфигурации трассы с локальной библиотекой. После проверки поиск также понимает локальные названия и ID. Серверы с недоступным или некорректным INFO скрываются этим фильтром; число непроверенных серверов показано отдельно. Проверка подтверждает наличие контента, а совместимость версий и checksum проверяет игра. Источник показан в интерфейсе. Это снимок каталога, а не обещание доступности сервера. При изменении формата каталога приложение сообщает об ошибке; можно продолжить по прямому адресу.

Нажмите сервер, чтобы запросить его `/INFO` и `/JSON|0` напрямую. Укажите имя, выберите установленную машину со свободным местом и нажмите «Подключиться». Также можно вставить `host:HTTP-порт`, URL `/INFO`, приглашение `acmanager://race/online/join?ip=…&httpPort=…` или ссылку Content Manager. HTTP-порт обычно отличается от TCP-порта игры: последний берётся из ответа сервера.

Нужны установленные версии всех используемых машин и трассы, совпадающие с сервером. Предварительная проверка отмечает выбранную машину и трассу; окончательную проверку версий и контрольных сумм выполняет сама игра. Устанавливайте недостающий контент через «Моды». Поддерживаются серверы с `pickup=1`, включая требующие CSP, если в выбранной игре установлен и включён патч подходящей сборки. Бронирование мест пока не поддерживается. Приложение проверяет локальные требования до запуска; реальное подключение и совместимость CSP с Wine и конкретным сервером проверяются в заезде.

Подключение использует обычный вход в Windows Steam и его ActiveUser; проверку владения игрой выполняет Steam. Каталог и просмотр мест не получают Steam ID. Имя, пароль и Steam ID не входят в пресеты или историю; пароль передаётся игре через временную секцию REMOTE в race.ini и очищается по завершении/ошибке запуска. Онлайн-история содержит название сервера; онлайн-времена не участвуют в локальном рекорде пресета, поскольку условия задаёт сервер.

Офлайн-проверки: `python3 Scripts/check-online.py` и `.build/release/MozaPaddock --self-test --without-game`. Они используют локальный HTTP-сервер и временные конфигурации без аккаунта. Ручная сетевая проверка: `python3 Scripts/paddock-online.py list --query magione`, затем `inspect --address host:HTTP-порт`. Успешный ответ INFO подтверждает просмотр; завершённый заезд проверяется отдельно. На настроенном Mac проверено реальное TCP-подключение и начало удалённой сессии BMW M3 E30 / Magione на обычном pickup-сервере. Холодный старт дополнительно ожидает готовность настоящего Steam API.

## Протокол и границы

`Scripts/online/servers.py` — собственная реализация адаптера публичного каталога и ограниченных HTTP-запросов (10 секунд, ограничение размера). Данные SSR читаются как JSON, JavaScript не исполняется. `OnlineBrowser` выполняет запросы вне UI-потока; `OnlineConnection` валидирует и записывает подключение; общий launcher сохраняет внешний экран, управление и закрытие Steam/Wine.

Форматы сверены с первичными источниками: [KunosApiProvider](https://github.com/gro-ove/actools/blob/master/AcManager.Tools/Helpers/Api/KunosApiProvider.cs), [ServerActualCarInformation](https://github.com/gro-ove/actools/blob/master/AcManager.Tools/Helpers/Api/Kunos/ServerActualCarInformation.cs), [Game.OnlineProperties](https://github.com/gro-ove/actools/blob/master/AcTools/Processes/Game.Properties.cs) и [описанием каталога](https://acservers.online/about). Код этих проектов не копируется и не поставляется.

## LAN

В «Онлайн → Серверы» доступны вкладки «Интернет» и «LAN». LAN ищет AC-серверы на этом Mac и через broadcast активных интерфейсов. По умолчанию проверяются игровые UDP-порты 9600–9610; диапазон можно изменить (например, `9600,19600`, не больше 64 портов). Обнаруженный HTTP-порт может отличаться от игрового: он берётся из ответа сервера, затем проверяются INFO/JSON. Одинаковые ответы объединяются.

Для VPN без broadcast, Wi-Fi с изоляцией клиентов и нестандартных портов остаётся ввод `IP:HTTP-порт`. Роутер и firewall не меняются. Сетевая доступность с другого устройства не подтверждается одним обнаружением на собственном Mac. Протокол обнаружения сверен с [исходником Content Manager](https://github.com/gro-ove/actools/blob/master/AcManager.Tools/Helpers/Api/KunosApiProvider.Lan.cs).

Фильтры трассы, автомобиля, свободных мест и «Есть все моды» также применяются к результатам LAN-поиска. Для LAN точные ID уже получены при обнаружении через INFO; переключение фильтра не требует интернет-каталога.

## Проверка CSP при подключении

Из INFO читается минимальный build CSP в обёртке идентификатора трассы `csp/<build>/../<track>` (также старый вариант без `csp/` и вариант с флагами). В библиотеке ищется очищенный ID трассы; произвольные пути с `..` не нормализуются. Зарезервированный build 999999 означает запрет активного CSP. Формат сверен с [ServerEntry](https://github.com/gro-ove/actools/blob/master/AcManager.Tools/Managers/Online/ServerEntry.cs) и [ServerPresetObject](https://github.com/gro-ove/actools/blob/master/AcManager.Tools/Objects/ServerPresetObject.cs).

`CSPInstallation` читает `dwrite.dll`, `extension/config/data_manifest.ini` (`SHADERS_PATCH`, `SHADERS_PATCH_BUILD`) и эффективный `BASIC/ENABLED` из `general.ini`, с приоритетом `Documents/Assetto Corsa/cfg/extension/general.ini`. Чтение версии и настроек соответствует [PatchHelper](https://github.com/gro-ove/actools/blob/master/AcManager.Tools/Data/PatchHelper.cs). Отсутствующий, отключённый, неизвестный или слишком старый патч даёт конкретную причину. Для совместимой установки UI разрешает вход вместо прежнего безусловного запрета. Требования повторно проверяются после свежего INFO и перед записью REMOTE. Перед CSP-входом launcher задаёт override `dwrite=native,builtin` только для `acs.exe` выбранной среды; онлайн-INI объявляет `HEADER/__CM_FEATURE_SET=2`. Установка или обновление CSP автоматически не выполняется.

Офлайн-регрессии покрывают разбор обёртки, настройки и их приоритет, сравнение build, обычный сервер без CSP и запись параметров подключения. Это не проверка реального заезда на CSP-сервере.
